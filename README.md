<summary><b>02 &nbsp; InterviewForge AI</b> &nbsp; — &nbsp; Local RAG Interview Coach</summary>

<br>

An interview-preparation app with **document Q&A, mock interviews, and Python study**, using **ChromaDB** and **Llama 3.2 through Ollama**.

- Implemented PDF ingestion, chunking, embeddings, and **persistent ChromaDB storage**.
- Retrieved the **top 3 chunks** to ground **Llama 3.2** answers through **Ollama**.
- Implemented adaptive **5-question practice sessions** with **0–10 scores**, feedback, and hints.

**Built with:** `Python` `FastAPI` `React` `ChromaDB` `Ollama` `Llama 3.2`

**Measured smoke test:** 6/6 factual answers correct, 2/2 unsupported questions declined, relevant passage ranked first in 6/6 cases; median response **6.41 s** on CPU. Small set: two PDFs, three chunks. [Method, raw results & full interview demo](./docs/demos/interviewforge-evaluation.md).

[**Watch the real PDF-to-answer demonstration ↗**](./docs/demos/interviewforge.md) · [Source & architecture ↗](https://github.com/Sumanthduasanapudi/InterviewForge-AI)

<img src="./assets/projects/interviewforge-live-answer.png" width="100%" alt="Real InterviewForge answer generated by Llama 3.2 with its PDF source expanded">

<sub>Actual local capture: PDF upload, retrieval, and a real Llama 3.2 answer with expanded sources. A separate unsupported-question check correctly declined to invent a salary. The full five-question scoring UI also completed; [evaluation results](./docs/demos/interviewforge-evaluation.md) document grading inconsistencies and repeated questions.</sub>
